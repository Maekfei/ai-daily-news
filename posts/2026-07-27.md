## 🎯 Agent 重点

### 1. 月之暗面（Moonshot AI）如期开源 Kimi K3，2.8T MoE 参数登顶开源前沿
- **要点**：Kimi K3 完整权重按官方 7 月 17 日博客承诺，于**今日（2026-07-27）**放出，成为全球首个 3T 级开源 MoE 模型。
- **详情**：Kimi K3 采用稀疏 MoE 架构，**总参数 2.8 万亿**，激活参数约 320B，原生视觉理解 + **100 万 token 上下文窗口**；官方将其定位为"开放前沿智能（Open Frontier Intelligence）"。据 VentureBeat 报道，其在多项 agent、代码、推理基准上已接近 Claude Opus 5 / GPT-5.6 Sol 等前沿闭源模型。伴随开源，月之暗面估值已上冲至 **315 亿美元、ARR 突破 3 亿美元**，公司正筹划最快 6 个月内赴港上市。上周（7 月 19 日）Kimi 团队因请求量逼近集群上限一度**暂停会员开放**，可见热度。
- **影响**：中国开源阵营在 DeepSeek-R1 之后，第二次以"权重全开 + 前沿性能"的组合冲击海外闭源生态，将进一步压低企业自建 Agent 的模型成本地板，也把美国监管针对国产开源的讨论再次推向前台。

### 2. OpenAI 智能体产品线一周用量再涨 2.5 倍，Codex 与 ChatGPT Work 深度合并
- **要点**：Sam Altman 在 X 披露，Codex + ChatGPT Work 上一周 token 用量环比增长 **2.5 倍**，GPT-5.6 上线两周成为 OpenAI 增速最快的 Agent 底座。
- **详情**：GPT-5.6 系列（旗舰 Sol、均衡 Terra、性价比 Luna）于 6 月下旬发布后，OpenAI 于 7 月 10 日在 ChatGPT、Codex、桌面客户端全面上线，随即在开发者中触发爆发式采用；本月上旬 OpenAI 还完成对德国云端开发环境公司 **Ona（原 Gitpod）**的收购，为 Codex 补齐"随时在云端跑一整个仓库"的持久化沙箱。**Codex 周活用户已破 500 万**，桌面端本月新上多智能体命令中心（Multi-Agent Command Center），支持并行编排多个 Codex agent。
- **影响**：GPT-5.6 与新沙箱基建让 OpenAI 首次同时拥有"模型 + IDE + 云端 Runtime"完整栈，直接压制 Cursor / Devin 等纯上层 agent 玩家；企业采购 coding agent 的默认清单将出现新一轮洗牌。
- 🔗 [凤凰科技：奥尔特曼称 OpenAI 智能体 AI 用量一周增长 2.5 倍](https://tech.ifeng.com/c/8uko8JgQNQ9)
- 🔗 [AiToolsRecap：OpenAI 完成收购 Ona，Codex 迎持久化云沙箱](https://aitoolsrecap.com/Blog/openai-acquires-ona-gitpod-codex-persistent-2026)

### 3. MCP 迎来协议诞生以来最大规模升级，7 月 28 日无状态化版本发布在即
- **要点**：模型上下文协议 **MCP（Model Context Protocol）** 官方定于 **2026-07-28** 发布年度大版本，核心变更是**彻底去除 Session ID / 全面无状态化**，Breaking Changes 覆盖大多数现有 Server 实现。
- **详情**：新版本将 Session 状态改为通过请求头 + 幂等 token 承载，官方同时推出**MCP Registry** 官方目录服务；据 GitHub Top 1500 项目统计，MCP 生态 SDK **月下载量已达 9700 万次、注册 Server 突破 10 万**，Gemini 3.6 Flash、Claude Opus 5、GPT-5.6 均已宣布原生兼容。Anthropic、Google（A2A）双协议栈"TCP/IP 时刻"进一步坐实。
- **影响**：无状态化虽然让部署更简单、更适合 Serverless，但存量 Server / SDK 需要在 8 月完成迁移，短期内会出现兼容性阵痛。对企业 Agent 平台来说，这是重新评估工具接入策略的关键窗口。

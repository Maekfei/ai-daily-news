# 🤖 今日 AI 要闻 · 2026-08-14

> Anthropic 传出 10 月以 2 万亿美元估值 IPO 剑指史上最大规模；xAI Grok 4.6 与 DeepSeek V4 Pro 前后脚发布，Agent 长任务成新战场。

## 🎯 Agent 重点

### 1. xAI 发布 Grok 4.6，Agent 长任务能力对齐 GPT-5.6
- **要点**：马斯克旗下 xAI 于 8 月 12 日推出新一代旗舰模型 Grok 4.6，主打长程 Agent 与编程能力。
- **详情**：Grok 4.6 延续 1.5 万亿参数 V9 架构，主打"纯后训练（SFT + RL）"路线，在综合 9 项基准的 Artificial Analysis Intelligence Index 上取得 61 分，与 GPT-5.6 Sol 打平。官方强调其"能持续处理包含大量步骤的复杂任务"，涵盖资料研究、大型代码库处理、把产品构想转化为完整应用等场景，可通过 xAI API（Responses API / Chat Completions）和编程产品 Grok Build 调用，上下文窗口扩展至 50 万 token 级别。
- **影响**：在 Anthropic Opus、GPT-5.6 Sol、DeepSeek V4 Pro 密集迭代之下，Grok 4.6 把"长任务 Agent"从演示 demo 推向可交付 SLA，前沿闭源阵营的 Agent 能力再次被拉齐。
- 🔗 [腾讯新闻：xAI 发布 Grok4.6 模型](https://news.qq.com/rain/a/20260813A00LN700)
- 🔗 [OSCHINA：Grok 4.6 智能指数追平 GPT-5.6 Sol](https://www.oschina.net/news/501917/grok-4-6)

### 2. DeepSeek V4 Pro 深夜上线：100 万上下文、官方预告涨价
- **要点**：DeepSeek 8 月 12 日晚间未做预热，直接把 V4 Pro 正式版通过 API 上线。
- **详情**：新版本模型名 `deepseek-v4-pro-0813`，原生支持 100 万 token 上下文，官方在文档中同时预告"近期将大幅上调 API 价格"，被解读为 DeepSeek 首次结束近一年的"补贴期"。据多家实测，V4 Pro 在编程 / Agent 基准上进一步逼近 Claude Fable 5 与 GPT-5.6 Sol，是当前最具性价比的开源系可用旗舰之一。
- **影响**：叠加同日发布的 Grok 4.6，Agent 编程赛道的模型层"卷"到极限——接下来的差异化将主要发生在 Harness/工具/上下文工程层，而非底座 benchmark。
- 🔗 [rexai：DeepSeek V4 Pro 0813 发布，1M 上下文](https://rexai.top/posts/2026-08-13-deepseek-v4-pro-0813/)
- 🔗 [九州量子：DeepSeek V4 Pro 深夜上线，性能逼近 Fable 5](https://www.jzl.com/industry-news/deepseek-v4-pro)

### 3. Anthropic 传 10 月冲刺 2 万亿美元 IPO，或成史上最大
- **要点**：多家外媒援引投资方消息称 Anthropic 计划 10 月挂牌，估值预计突破 2 万亿美元。
- **详情**：若落地，将超越 SpaceX 此前 1.77 万亿美元的 IPO 纪录，问鼎史上规模最大的首次公开募股，部分投资人给出的乐观估值高达 3 万亿美元。参考锚点：Anthropic 5 月刚以 9650 亿美元投后估值完成 650 亿美元 H 轮（Altimeter、Dragoneer、Greenoaks、红杉领投），当前年化收入约 470 亿美元。8 月 13 日多方证实其**首次实现盈利**——成为前沿实验室"造血"可行性的关键信号。
- **影响**：作为 Claude / Claude Code 的母公司，Anthropic 上市将把 Agent 生态的估值锚点定死在"万亿美元级"，直接推高 OpenAI 后续融资定价与整个 Agentic AI 板块估值。

### 4. Anthropic 官宣：Claude 所有文本输出将加水印以合规 EU AI Act
- **要点**：Anthropic 宣布将对 Claude 全线模型的文本输出嵌入不可见水印，图片走 C2PA 元数据。
- **详情**：EU AI Act 于 8 月 2 日正式进入执法期，其中"合成内容标识"是核心条款之一。Anthropic 是首家公开承诺按 EU 规则给**文本**加水印的前沿实验室——之前的水印讨论主要集中在图像、视频。方案是"欧盟境内启动的模型全部启用，全球用户也逐步铺开"，具体技术细节称基于 Google DeepMind 早前开源的 SynthID 变体。
- **影响**：对以 Claude 为底座的 Agent 应用（包括所有 Claude Code、MCP 生态工具）而言，输出内容将天然带上"AI 生成"标记，改变新闻、法律、教育等下游对 Agent 输出的信任与合规链路。
- 🔗 [TechCrunch：Anthropic says it will watermark text](https://techcrunch.com/2026/08/11/anthropic-says-it-will-watermark-text-generated-by-its-ai-models/)
- 🔗 [Unite.AI：Anthropic Watermarks Claude Text Output to Meet EU Transparency Rules](https://www.unite.ai/anthropic-watermarks-claude-text-output-to-meet-eu-transparency-rules/)

### 5. Google DeepMind 推出 Gemini 3.7 Flash，主攻工程 Agent
- **要点**：DeepMind 8 月 13 日发布 Gemini 3 家族新成员 Gemini 3.7 Flash，主打软件工程与 Web 开发。
- **详情**：官方 Model Card 描述新版在"软件工程、Web 开发"两大方向作了算法级改进，Gemini API changelog 同步上线 `gemini-3.7-flash` 模型，相比 3.5 Flash 在 SWE-bench 类 benchmark 有"substantial improvements"。定位仍是"高性价比长上下文 Agent 底座"，与 Vertex AI Code Assist 深度打通。
- **影响**：Gemini 系列"用便宜模型跑 Agent 长循环"的策略进一步强化，直接对标 DeepSeek V4 Flash 与 Claude Haiku，成为企业侧 Agent 部署的重要成本选项。
- 🔗 [Google DeepMind：Gemini 3.7 Flash Model Card](https://deepmind.google/models/model-cards/gemini-3-7-flash/)
- 🔗 [Google AI Developers：Gemini API changelog](https://ai.google.dev/gemini-api/docs/changelog)

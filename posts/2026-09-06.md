# 🤖 今日 AI 要闻 · 2026-09-06

> 今日主线延续本周"前沿模型 + 巨额算力"双轮：GPT-6 Astra 面向开发者全量开放并释出 Computer Use / Codex 新能力；同时英伟达 129.3 亿美元收购 Hugging Face 的余波持续冲击开源生态与 Agent 供应链。

## 🎯 Agent 重点

### 1. OpenAI 面向开发者全量开放 GPT-6 Astra，Computer Use 与 Codex 升级
- **要点**：Astra 首次把"计算机操作 + 浏览器 + 长链路编码"打包成为默认 API 能力。
- **详情**：北京时间 9 月 5 日，OpenAI 通过官方博客与 Simon Willison 的技术摘要同步放出《Introducing GPT-6 Astra for developers》，明确 API 定价 **10 美元 / 50 美元 每百万输入 / 输出 token**，最大上下文 **105 万 token**、最大输出 **12.8 万 token**，并原生支持 Computer Use、浏览器工具、代码执行、结构化输出等 Agent 能力。ChatGPT Plus/Pro 侧的额度也在今天完成重置并接入 Astra 后端。
- **影响**：这是继 GPT-5 之后首个把"长时任务 + 屏幕/浏览器操作"作为一等公民的旗舰版本，直接把 Manus、Devin、Claude Code 等竞品拉入下一轮 Agent 能力赛。定价对企业开发者相对友好，会加速传统 SaaS 向 agentic 工作流迁移。
- 🔗 [Simon Willison — Introducing GPT-6 Astra for developers](https://simonwillison.net/2026/Sep/5/introducing-gpt-6-astra-for-developers/)
- 🔗 [ComputingForGeeks — GPT-6 Astra: Benchmarks, Pricing and API](https://computingforgeeks.com/gpt-6-astra-released-features-benchmarks/)

### 2. NVIDIA 129.3 亿美元收购 Hugging Face，冲击开源 Agent 供应链
- **要点**：史上最大规模开源 AI 平台并购案落地，Hugging Face 将并入英伟达全栈战略。
- **详情**：9 月 3 日 NVIDIA 官方博客与 TechCrunch 同步确认，NVIDIA 以 **129.3 亿美元**（全现金＋股权）完成对 Hugging Face 的收购，交易文件披露 Hugging Face 上活跃模型仓库超 **170 万个**、月活开发者约 **900 万**。NVIDIA 表示将扩容 HF 平台基础设施，并把 NIM 微服务、CUDA 优化工具链与 HF Hub 深度打通。早期投资人 Kevin Durant 的这笔投资据报回报约 **240 倍**。
- **影响**：短期 HF 仍以中立开源社区姿态运行，但长期 Agent 框架（LangGraph / CrewAI / AutoGen 等）越来越多依赖 HF 模型分发，控制权集中到芯片厂将重塑开源 Agent 生态的议价结构与合规边界。
- 🔗 [NVIDIA 官方博客 — NVIDIA to Acquire Hugging Face](https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/)
- 🔗 [TechCrunch — Nvidia confirms it will buy Hugging Face for $12.9 billion](https://techcrunch.com/2026/09/03/nvidia-confirms-it-will-buy-hugging-face-for-12-9-billion/)

### 3. Anthropic 发布 Claude Fable 5.1 / Mythos 5.1，缓存降价 75%、Agent 成本再降 45%
- **要点**：面向 Agent 长任务优化的编程/知识工作旗舰双子座模型上线。
- **详情**：9 月 1 日 Anthropic 推出 **Claude Fable 5.1**（面向所有开发者与企业）与 **Claude Mythos 5.1**（仅通过白名单向美国网络安全和生命科学机构开放）。官方数据：Terminal-Bench-Science 0.1 得分 **52.6%**（前代翻倍）、编程基准提升 **13%**、典型工作负载 token 成本降低 **25%**，Agent 场景（大量重复上下文）可省 **45%**；prompt caching 定价直接下调 **75%**。同日 Anthropic 与英伟达支持的云服务商 Lambda 签下 **350 亿美元、6 年、350 MW** 的算力大单。
- **影响**：Fable 5.1 把"编码 + 长链路 Agent"打成价格 / 能力平衡点，直接卡位在 GPT-6 Astra 之下，是 Claude Code / Cursor / OpenClaw 等编码 Agent 的默认新底座；350 亿云单则宣告 Anthropic 已彻底从"OpenAI 的替代品"进入独立算力时代。
- 🔗 [IT之家 — Anthropic 发布 Claude Fable 5.1 和 Mythos 5.1，缓存降价 75%](https://www.ithome.com/0/997/193.htm)
- 🔗 [GuruFocus — Anthropic Signs $35 Billion Cloud Deal with Lambda](https://www.gurufocus.com/news/9061335/anthropic-signs-35-billion-cloud-deal-with-lambda-supported-by-nvidia)

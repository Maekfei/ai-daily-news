## 🎯 Agent 重点

### 1. SpaceX 完成 600 亿美元收购 Cursor，编程 Agent 并入 Grok 版图
- **要点**：xAI/SpaceX 用一次 all-stock 交易，把最热编程 Agent 平台 Cursor 装进自家 Grok 生态。
- **详情**：8 月 14 日晚间至 15 日，SpaceX 正式官宣完成对 Cursor 母公司 Anysphere 的收购交割，交易结构为约 600 亿美元全股票对价，Cursor 团队与产品线并入 SpaceXAI（原 xAI）旗下的 Grok 组织。Cursor 品牌保留独立运营，但底层将逐步接入 Grok 4.6 模型、Colossus 算力集群和 xAI 企业销售网络。这也意味着继 4 月宣布意向、6 月披露条款后，历时约 4 个月的编程 Agent 领域最大并购正式落地。
- **影响**：Coding Agent 赛道从"模型 + IDE"竞争转向"算力 + 模型 + IDE 一体化"，Cursor 拿到近乎无限的算力后端，与 Claude Code、GitHub Copilot、字节 Trae 的差距或将快速拉开；同时也把马斯克旗下 AI 从聊天/搜索延伸至开发者入口。
- 🔗 [TechCrunch：SpaceX officially closes its Cursor acquisition](https://techcrunch.com/2026/08/15/spacex-officially-closes-its-cursor-acquisition/)
- 🔗 [ExplainX：SpaceX Closes $60B Cursor Acquisition — Cursor Joins the Grok Org](https://www.explainx.ai/blog/spacex-cursor-acquisition-closed-grok-branding-august-2026)

### 2. LangChain 正式公测 Managed Deep Agents，Agent 进入"托管运行时"时代
- **要点**：LangChain 把 Deep Agents 从开源 SDK 升级为 API 优先的托管平台，一条 CLI 命令部署生产级智能体。
- **详情**：Managed Deep Agents（MDA）从 8 月初进入 public beta 后持续放量，8 月 15 日在 Docs 与 changelog 同步收录为正式产品，内置 Deep Agents Harness（规划-工具-文件系统-记忆的智能体主循环）、沙箱、长上下文记忆和 LangSmith 观测，开发者通过 `mda deploy` 即可把智能体推到生产环境，不再需要自建 Kubernetes、沙箱和 trace 后端。LangChain 官方博客将其定位为"最快的生产级 Deep Agent 部署方案"。
- **影响**：与 DeepSeek Harness、Anthropic Managed Agents、Google Vertex Agents 一起，Agent 基础设施进入"托管运行时"竞赛阶段——开发者关注点从"写 Agent"转到"选择哪个平台跑 Agent"，中间件公司（LangChain、LlamaIndex）与模型厂商正面对撞。
- 🔗 [LangChain Docs：Managed Deep Agents Overview](https://docs.langchain.com/langsmith/python/managed-deep-agents-overview)
- 🔗 [aitoolly：LangChain Introduces Managed Deep Agents (2026-08-13)](https://aitoolly.com/ai-news/article/2026-08-13-langchain-introduces-managed-deep-agents-a-new-standard-for-building-and-deploying-ai-agents)

### 3. Databricks 完成 50 亿美元 J 轮，1900 亿美元估值发布 Lakebase Agentic Postgres
- **要点**：Databricks 一边刷新私募 AI 数据平台估值上限，一边把"面向 Agent 的 Postgres"作为下一个增长引擎。
- **详情**：8 月 13–14 日，Databricks 正式官宣完成 50 亿美元 J 轮融资，估值升至 1900 亿美元，较半年前 1340 亿美元上涨约 42%，Coatue 领投，黑石、MGX、T. Rowe Price、Sixth Street Growth 参投；公司披露年化收入已突破 70 亿美元，Q2 同比增长超 80%。融资官宣同日发布 Lakebase Agentic Postgres，把 Lakehouse 与 OLTP 融合，为 AI Agent 提供毫秒级读写、事务保证与向量原生检索。
- **影响**：这是继 SpaceX 之后年内最大规模的私募融资之一，进一步坐实"数据平台是 Agent 时代的关键基座"的行业共识；同时也把 Snowflake、MongoDB、Postgres 云服务商挤入正面 Agent 数据战场。

### 4. 智谱 GLM-5.3 发布漏洞战报：AI Agent 一个月挖出 2436 个真实开源漏洞
- **要点**：GLM-5.3 把"AI 自动挖漏洞"从 demo 推到规模化生产，覆盖 FreeBSD、Cursor、DNS 协议级组件。
- **详情**：8 月 14 日智谱正式发布 GLM-5.3（编程能力较 5.2 提升约 50%），并在 CyberGym 漏洞挖掘基准中刷新纪录；8 月 16 日发布运行战报——过去一个月 GLM-5.3 驱动的自动化 Agent 在 FreeBSD、Cursor 客户端、DNS 协议实现等大量开源项目中挖出 2436 个可复现真实漏洞，另有 Neo AI 相关钓鱼样本联动分析。模型权重定于发布后两周开源，中间时段用于安全评估与加固。
- **影响**：Agent 化的安全能力成为大模型的新的差异化维度，甚至可能改写攻防非对称格局；对开源生态既是巨大红利（大量陈年漏洞被修复）也是安全考验，"模型即武器"的监管讨论会被再次点燃。

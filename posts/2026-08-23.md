## 🎯 Agent 重点

### 1. Nvidia 60 亿美元买断 Poolside "模型工厂"授权 + 追加 10 亿股权投资
- **要点**：英伟达以 **60 亿美元非独占授权费**取得 Poolside 端到端"模型工厂"（Model Factory）技术，另追加 **10 亿美元**股权投资，并向其 **109 名员工**发出录用邀约，是英伟达近期最大规模 AI Agent 相关战略投资。
- **详情**：据 Newcomer 获取的投资人信件及多家科技媒体 8 月 21-22 日报道，Poolside 是主打企业级编程 Agent 的 AI 初创公司，其"模型工厂"覆盖数据处理、预训练、强化学习、评估到部署的全栈基础设施。此次交易结构包括 60 亿美元技术授权（分期支付）+ 10 亿美元股权融资 + 大规模人才吸纳，Nvidia 将把该套技术栈整合进其自有 AI Enterprise / DGX Cloud 产品线，直接服务金融、政府等需要私有化训练的大客户。这是继黄仁勋此前透露 Blackwell + Vera Rubin 芯片订单预期达"万亿美元"级别之后，Nvidia 在软件层最激进的一次外部技术采购。
- **影响**：Nvidia 首次系统性把"卖算力 → 卖端到端模型建造能力"打包，直接与 AWS Bedrock、Azure AI Foundry、Google Vertex 抢企业级 Agent 训练平台入口；对 Cursor、Anthropic、Cognition 等 Agent 编程厂商构成"上游供应商开始下场做半成品"的挤压。

### 2. Anthropic 冲刺 2 万亿美元 IPO，挖谷歌 TPU 创始人自研芯片
- **要点**：Claude 母公司 Anthropic 在冲刺 **2 万亿美元估值 IPO** 的关键窗口，挖来前谷歌 TPU 业务创始人主导自研芯片，同时与 Fractile 签约约 **2.5 亿美元**采购、并锁定 2027 年约 **3.5 GW** 的下一代 TPU 容量。
- **详情**：8 月 21-22 日多家中文财经媒体披露，Anthropic 一方面推进有史以来最大规模 IPO 招股（募资目标一度传至 862 亿美元），另一方面在算力上"两条腿走路"：外部采购层面已扩大与谷歌、博通合作，计划与三星联合设计定制硬件；内部自研层面则从谷歌挖来主导 TPU 业务的核心创始人，配合 8 月 21 日博通宣布洽谈 **700–800 亿美元**债务融资为 AI 芯片订单铺底，被市场解读为 Anthropic 冲刺 IPO 前的"去英伟达化"豪赌。年化营收 (ARR) 已在 8 月中旬报告冲上 **650 亿美元**，Agent（Claude Code / Skills / Sonnet API）为主要增量。
- **影响**：这是"Agent 时代"首个前沿模型公司公开挑战 2 万亿美元估值锚定，将直接抬高 OpenAI、xAI、DeepSeek 等竞对的融资/上市对标线；也宣告顶级模型厂商纷纷从"抢 GPU"转向"造自己的 XPU"，Nvidia 通用 GPU 的议价权面临结构性稀释。

### 3. 阿里发布 Qwen-UI-Agent：真机训练的 GUI 智能体基座模型
- **要点**：阿里千问 8 月 20 日晚正式发布 **Qwen-UI-Agent**——覆盖手机、PC、网页与深度搜索的 GUI Agent 基座模型，MobileWorld-Real 真机基准 **92.2%**、AndroidDaily **97.5%**，六项核心基准取得五项第一。
- **详情**：Qwen-UI-Agent 主打"以真实世界为中心"的训练范式，搭建了覆盖 **100+ 台真实手机、150+ 应用**的真机移动环境用于任务构建与在线强化学习。移动端 MobileWorld 得分 82.1%、真机版 MobileWorld-Real 达到 92.2%、AndroidDaily 97.5%，多数指标对标乃至超越 Anthropic Computer Use 与 OpenAI Operator 系列。发布次日（8 月 21-22 日），软盟资讯、AI 工具实验室等多家渠道追加报道，称其为"国内首个把真机训练做成基座能力的 GUI Agent 模型"。
- **影响**：GUI Agent 从 demo 走向真机基座意味着国产 Agent 生态首次拥有和海外并跑的**屏幕执行层能力**——为电商、金融 App、政务办公等封闭生态 Agent 化提供了底层基座，短期内会加速国内 Agent 应用侧集中放量。

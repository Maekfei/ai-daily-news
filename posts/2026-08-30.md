## 🎯 Agent 重点

### 1. OpenAI 宣布 11 月 12 日起终止向 Cursor 提供模型
- **要点**：SpaceX 以约 600 亿美元收购 Cursor 后，OpenAI 决定切断模型 API 供应。
- **详情**：当地时间 8 月 28 日，OpenAI 发布官方声明，已正式通知 SpaceX 计划终止与 Cursor 的合作合同，拟定服务停止日期为 2026 年 11 月 12 日，按合同规定的最长期限提前通知。OpenAI 在声明中援引 Elon Musk 此前多次违约的历史作为决策理由，同时表示希望"尽量延长开发者在 Cursor 中使用 OpenAI 模型的时间"。Cursor 曾是 OpenAI 模型最重要的消费端渠道之一，年收入据估计已达 3–5 亿美元。
- **影响**：这是 AI Coding Agent 赛道第一次出现"模型断供"级冲突，凸显了平台型 Agent 产品对底层模型供应商的深度依赖；Anthropic Claude 与 Google Gemini 有望成为 Cursor 的主力替代模型，行业开始重新评估供应链风险。
- 🔗 [OpenAI 官方声明：Our decision on Cursor following its acquisition by SpaceX](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/)
- 🔗 [CNBC · OpenAI to end model access to Cursor after SpaceX acquisition](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)

### 2. Anthropic 发布 Model Hardware Standard（MHS）研究预览
- **要点**：Anthropic 推出面向硬件设备的统一协议，让 AI Agent 安全地"接管"显微镜、机械臂、量子计算机等物理装置。
- **详情**：8 月 27 日，Anthropic 联合霍华德·休斯医学研究所（HHMI）Janelia 研究园区，公开 Model Hardware Standard（MHS）研究预览版。MHS 可以理解为面向物理硬件的 MCP：定义了设备发现、能力描述、安全指令与紧急停止的统一规范，让同一份 Agent 代码可以驱动不同厂商的仪器。首批合作伙伴包括 Janelia 的自动化生物实验室、以及若干量子计算与机械臂厂商，Anthropic 表示会将协议规范开源以吸引更多硬件商接入。
- **影响**：如果 MCP 让 Agent 学会"用软件"，MHS 就是让 Agent 学会"用硬件"，是 AI 从数字世界走向物理世界的关键中间层，也是与 Google A2A / A2UI 协议在 Agent 标准化战场上的正面竞争。
- 🔗 [Anthropic 官方博客 · Previewing the Model Hardware Standard](https://www.anthropic.com/news/model-hardware-standard-research-preview)
- 🔗 [腾讯新闻 · Anthropic 做了个通用"接口"，Agent 开始接管显微镜、机械臂和量子计算机](https://news.qq.com/rain/a/20260828A0ASKU00)

### 3. Anthropic 拟 9 月上旬公布 IPO 招股书，目标募资 1300 亿美元
- **要点**：Claude 母公司 Anthropic 冲刺史上最大 IPO，估值有望超越 SpaceX。
- **详情**：据知情人士透露，Anthropic 计划在美国劳动节（9 月 7 日）后公布招股说明书，9 月中旬举办投资者日，最快 9 月下旬或 10 月初正式登陆美股。公司此前已于今年 6 月向 SEC 秘密提交 S-1 草案，目标 IPO 募资至少 1300 亿美元，超过 SpaceX 今年 6 月创下的 860 亿美元募资纪录。Anthropic 还在设计一种非常规的股权结构，允许现有股东在 IPO 中直接出售股份，部分股东锁定期可能超过 180 天。
- **影响**：作为 Claude 及 Claude Code 的开发商，Anthropic 上市将为 Agent 生态提供"最大规模纯 AI 资本样本"，同时也让 OpenAI 面临更直接的资本市场对标压力。

### 4. Perplexity 联手 NVIDIA 推出全本地 Agent "Portable Computer"
- **要点**：把 Agent 装进桌面盒子，零 Token 成本、离线可用。
- **详情**：Perplexity 宣布与 NVIDIA 合作，正式推出 Portable Computer——一款基于 NVIDIA DGX Spark 硬件、完全本地运行的 Agent 设备。启动阶段可选择 Qwen 3.8 27B 或 Perplexity 自研的 PPLX 27B 模型，未来还将接入 NVIDIA Nemotron 3.5 Lightning（30B）；用户可选择性调用云端更强模型作为升级路径。整机对企业推销的核心卖点是"零 per-token 推理成本"和"数据不出本地"。
- **影响**：这是 2026 年 Agent 硬件化最具代表性的产品之一，与 Anthropic MHS、字节豆包 AI 手机同属"端侧 Agent 元年"信号，可能重塑企业 AI 采购模式。
- 🔗 [AI Market Watch · Perplexity and NVIDIA launch Portable Computer, a fully local AI agent](https://www.ai-market-watch.com/news/perplexity-and-nvidia-launch-portable-computer-a-fully-local-ai-agent-with-zero--kyx83w)
- 🔗 [AI 产品库 · Perplexity 联手英伟达推本地 AI 代理](https://aiproducthub.cn/newsflash/perplexity-portable-computer-nvidia-dgx-spark-local-agent/)

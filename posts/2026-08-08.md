> xAI 如期上线 **Grok 4.6**（1.5 万亿参数，SFT/RL 双升级），马斯克预告数周内的 2.1 万亿参数 Grok 4.7；同日《金融时报》披露字节跳动已开始预训练一个高达 **10 万亿参数**的巨型模型，直接对标 Anthropic 前沿系统——中美一线实验室的"参数—算力—Agent 能力"三线竞速再次升级。

## 🎯 Agent 重点

### 1. xAI 发布 Grok 4.6：1.5 万亿参数，SFT 与 RL 双升级、几周内跟进 Grok 4.7
- **要点**：马斯克宣布 xAI 于 **8 月 7 日前后**正式发布 Grok 4.6，参数规模达 **1.5 万亿**，几周后再推出 **2.1 万亿**参数的 Grok 4.7；SpaceX 全量数据将投入训练。
- **详情**：Grok 4.6 相较 7 月发布的 Grok 4.5 在**监督微调（SFT）**与**强化学习（RL）**两条主干上实现显著改进，主打代码、财务、法律等长链任务的自主执行；xAI 首次官方披露将 SpaceX 全量业务数据用于训练，配合 Anthropic-SpaceX 上周披露的算力合作，形成"数据 + 算力 + 模型"三角闭环。Grok 4.7 参数规模预计 **2.1 万亿**，将主要提升多模态与推理深度。发布节奏罕见地被马斯克在 SpaceX 首次财报电话会（8 月 4 日）公开预告，意在把 xAI 从"Grok 版本战"抬升到"月度 Cadence"竞争层。
- **影响**：xAI 与 OpenAI GPT-5.6 系列、Anthropic Mythos 5、Google Gemini 形成四强月度迭代赛；1.5→2.1 万亿参数、"几周一版"的公开节奏，事实上把大模型军备竞赛的技术透明度进一步下压，Agent 采购方将被迫更频繁重评底座；同时 SpaceX 数据入模会引发新一轮"专有数据护城河"讨论。

### 2. 字节跳动开始预训练 10 万亿参数模型，对标 Anthropic Mythos 前沿系统
- **要点**：《金融时报》8 月 7 日披露，字节跳动已启动一个**参数规模高达 10 万亿**的大模型预训练，规模约为 Moonshot Kimi K3 的 **3 倍**，也大于市场对 Anthropic Mythos 5 的估计。
- **详情**：训练目前处于早期阶段，目标是缩小中国实验室与 Anthropic、OpenAI 顶尖模型的差距；10 万亿总参数意味着单次训练算力消耗将超过以往国内所有已公开模型。字节前序 Doubao Seed-2.1 Pro（260628）与 Muse Spark 系列已经在 Agent Coding 上取得进展，本次巨模型据报道将同时押注**多模态 + 长上下文 + Agentic 推理**三条技术路线。此项目在国内被解读为字节继火山方舟平台、豆包 App 之后的\"第三根支柱\"，也是**继 Kimi K3 后国内第二个万亿以上巨模型**的正式立项披露。
- **影响**：10 万亿参数级的立项，把中国大模型层的\"下限\"再次上调；配合 DeepSeek V4 系列、阿里 Qwen 3.8-Max（2.4 万亿 MoE，8 月中开源）、MiniMax H3，一场"多路径—多规模—多技术栈"的国产模型集群竞赛正式成型。对企业采购端，则意味着 Q4 起将出现更多"字节大模型 vs Anthropic Mythos"的直接同台比较。

### 3. LangChain 推出 Managed Deep Agents 公测：从原型直达生产的\"Agent Harness\"
- **要点**：LangChain 于 **8 月 7 日**开放 **Managed Deep Agents 公测**（Public Beta），把 Deep Agents 框架的**规划、记忆、子 Agent、Rubrics 自评估**四大能力包装为托管服务，主打\"prototype → production\"的一体化落地。
- **详情**：Managed Deep Agents 承接 6 月发布的 Rubrics（Agent 自我评估与纠错）、Fleet On-Call 副驾（跨 trace/code 的问题诊断 Agent）等能力，把 harness（运行时环境）从开源 SDK 升级为托管平台：内置检查点、可控超时、观测、Prompt 版本化以及与 LangSmith 的深度集成，用户可在网页/移动端启动 Deep Agent 会话并将其固化为 Routine。今年上半年 Deep Agents 已被 Box AI 等企业用于构建内容智能体平台，本次公测是其**首次以 Managed SaaS 形式对开发者开放**。
- **影响**：Agent Harness 是 2026 年公认的核心工程化层，LangChain 与 Anthropic Claude Code Self-Hosted、字节 DeerFlow 2.0、OpenClaw Skills 系统正在同一层竞争；对企业客户，Managed Deep Agents 意味着可以跳过自建 Runtime，直接以 SaaS 方式获得\"能长期做事的 Agent\"。

- 🔗 [GitHub：langchain-ai/deepagents Releases](https://github.com/langchain-ai/deepagents/releases)

### 4. Anthropic 开放 Claude Code \"Self-hosted environments\" 企业公测
- **要点**：Anthropic 于 **8 月 6 日**发布博客，宣布 **Claude Code 自托管环境** 进入公开测试——企业可在自己的基础设施上运行 Claude Code 云端会话。
- **详情**：Self-hosted environments 允许用户从 Web、移动端、桌面或 Routine 启动 Claude Code 会话，实际执行运行在客户自控的 runners 上，工具调用、文件、网络出站流量都不会离开企业内网。这是 Anthropic 在 3 月 Claude Code 源码泄漏事件、以及本周 GPT-5.6 沙箱逃逸事件后的强节奏合规回应，直接切入受监管行业（金融、医疗、政府）对"Agent 只能在企业内跑"的核心痛点。Faire 工程高级经理 George Jacob 是首批背书客户。
- **影响**：Claude Code 从\"最强 Coding Agent\"演进为\"最强合规 Coding Agent\"，与 Managed Agents 的沙箱能力形成组合拳；同时把\"自托管 + 云端体验\"抬为企业侧新标配，OpenAI Codex、Google Antigravity、字节 DeerFlow 等对手将被迫跟进。

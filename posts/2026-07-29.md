# 🤖 今日 AI 要闻 · 2026-07-29

> 美团正式发布 CatPaw 全场景 AI Agent 平台，同步开源 1.6T LongCat 2.0；月之暗面 Kimi K3 完整开源、Anthropic Claude Opus 5 定价"腰斩"，国产开源与前沿闭源双线共振。

## 🎯 Agent 重点

### 1. 美团发布 CatPaw 全场景 AI Agent 平台，LongCat 2.0 万亿模型开源
- **要点**：美团把自研万亿模型能力打包成企业级 Agent 平台，从"跑得动"推向"用得好"。
- **详情**：7 月 28 日，美团正式上线 CatPaw——搭载 LongCat 2.0 的全场景 AI Agent 平台，提供开箱即用的 AI 智能工作台与企业级 Agent 开发/托管能力，覆盖多 Agent 协作、工具调用、知识库 RAG 与长上下文处理。底层模型 LongCat 2.0 总参数 **1.6T**，平均激活 ~48B（动态范围 33B–56B），原生支持 **1M token** 上下文，是首个在**五万张国产算力卡**上完成全流程训练与推理的万亿参数模型。
- **影响**：意味着"自研万亿模型 → 全场景 Agent 平台"的国产闭环首次跑通，对企业 Agent 落地路径与国产算力生态都是一次实证。
- 🔗 [美团技术团队 · CatPaw / LongCat 官方发布](https://tech.meituan.com/2026/07/28/CatPaw-LongCat.html)

### 2. 月之暗面开源 Kimi K3：2.8T 参数 MoE，全球首个 3T 级开放权重模型
- **要点**：Kimi K3 完整权重于 7 月 27 日上传 Hugging Face，成为全球最大开源大模型。
- **详情**：月之暗面（Moonshot AI）Kimi K3 总参数 **2.8 万亿**、激活 1040 亿，原生支持视觉理解和 **100 万 token** 上下文，采用 Modified MIT 定制许可证。除权重外还同步开源了高性能注意力内核与 MoE kernels，Code Arena **1679 分**超越 GLM-5.2，在编程 / Agent / 视觉理解赛道与顶级闭源模型互有胜负。瑞银研报称其"性能已接近领先闭源前沿模型"，推理成本仅为闭源顶尖模型的**几分之一**。
- **影响**：将开源与闭源前沿模型的平均性能差距进一步压缩至约 3.3%，直接冲击 OpenAI / Anthropic 闭源商业模式，也让 OpenAI、Anthropic 加紧游说美国限制中国开源模型。
- 🔗 [中新社 · 中国 AI 开源大模型累计下载破 100 亿次](https://www.chinanews.com.cn/cj/2026/07-20/10663137.shtml)

### 3. 阿里 Qoder 上线 Qoder Voice：全双工语音驱动编程 Agent
- **要点**：编程 Agent 首次接入实时全双工语音，语音即可创建任务、调用工具。
- **详情**：7 月 28 日，阿里 Qoder 正式上线实时语音交互智能体 **Qoder Voice**，由全双工语音模型 **Qwen-Audio-3.0-Realtime** 驱动。用户可语音唤醒 Agent、实时双向对话，Agent 在后台同步创建任务、调用工具、生成代码与文档，将"IDE 内的手动敲键盘"进一步降级为"边说边做"。产品同时集成到 Qoder Cloud 与 Token Plan 订阅体系。
- **影响**：把编程 Agent 的入口从"编辑器"进一步推向"日常对话"，是国内首个将实时语音 + 编程 Agent 端到端打通的产品，对 Cursor / Claude Code / Codex 在本土市场是一次直接竞争。
- 🔗 [搜狐 · Qwen 3.8 在 Qoder 抢先开测](https://www.sohu.com/a/1052452588_121859399)

### 4. Moonshot 发布 PerceptionBench：所有前沿多模态模型视觉感知均不足 60%
- **要点**：新基准戳穿"多模态旗舰"表面高分，揭示视觉感知的系统性短板。
- **详情**：Moonshot AI 7 月 28 日前后发布并开源 **PerceptionBench**，从 42 个现有评测集中前沿模型的失败案例归纳出 **10 项原子视觉感知能力**，构建 **3000 道**隔离式验证题。测评结果显示 GPT-5.6、Claude Opus 5、Gemini 3.5 Pro、Kimi K3 等**没有任何一个前沿模型准确率超过 60%**，Agent 在浏览器、文档、UI 视觉推理上的"看错"是主要失败模式。
- **影响**：给依赖视觉输入的浏览器 Agent、GUI Agent、Robotics 团队浇了一盆冷水——benchmark 分数与真实感知能力存在系统性缺口，评测范式亟需重建。
- 🔗 [GitHub · MoonshotAI/PerceptionBench](https://github.com/MoonshotAI/PerceptionBench)

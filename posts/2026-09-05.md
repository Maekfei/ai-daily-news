## 🎯 Agent 重点

### 1. OpenAI 发布 GPT-6 Astra，Computer Use 与 Codex 打包上线
- **要点**：OpenAI 时隔一年推出新一代旗舰模型 GPT-6 "Astra"，重点押注 Agent 与"电脑操作"能力。
- **详情**：北京时间 9 月 4 日凌晨，OpenAI 总裁 Greg Brockman 在发布会上宣告"Welcome to the AGI era"。GPT-6 Astra 上下文窗口达 **105 万 tokens**（约 1500 页 A4），在 Computer Use、Codex、科学推理与长链路 Agent 场景全面升级，是首个被 Preparedness Framework 划入"关键（Critical）"网络安全能力的模型，在 ExploitBench 内部评测中获满分。9 月 5 日已面向 ChatGPT Work、Codex 的 Pro / Enterprise / Business Premium 用户开放，同时上线 API 及 AWS，Plus 与 Business 用户将于数日内推送。**API 价格约为上一代 2.5 倍**。
- **影响**：GPT-6 Astra 把"Computer Use + 编程 Agent + 网络安全"绑成一体，正式把"AI 员工"这个说法从营销词推向可交付形态；但更高的价格和分阶段放量也意味着企业侧要重新做成本/风险评估。Sam Altman 罕见在 X 上为发布日的"messy"上线公开道歉。

### 2. 英伟达 129 亿美元收购 Hugging Face，收编开源 Agent 生态入口
- **要点**：NVIDIA 宣布以 **约 129.3 亿美元**（约 113 亿英镑）收购全球最大开源 AI 平台 Hugging Face，创下公司史上最大并购。
- **详情**：交易于 9 月 3 日美东时间公布，Bloomberg 与 Bio-IT World 均已确认。Hugging Face 目前托管 200 万+ 模型、数据集和 Space，是 Agent / RAG / 微调链路的默认分发入口。NVIDIA 表示将保留品牌与独立运营，重点是把 NIM 微服务、AI Enterprise 与 Hugging Face Hub 打通，形成"CUDA + 模型仓库 + Agent 工具链"的一体化栈。
- **影响**：这次收购让"开源 = 中立公地"这条曾经被广泛信仰的规则出现明显裂缝，Cerebras、AMD、Groq 等竞对以及各国监管机构预计会介入审查；对下游 Agent 团队而言，短期使用体验不变，但模型分发、许可证与算力捆绑规则可能在未来一年重写。
- 🔗 [TechNode：Nvidia agrees to acquire Hugging Face for $12.93B](https://technode.global/2026/09/04/nvidia-hugging-face-acquisition-12-93-billion/)
- 🔗 [Bio-IT World：NVIDIA Acquires Hugging Face for $12.93 Billion](https://www.bio-itworld.com/news/2026/09/03/nvidia-acquires-hugging-face-for--12.93-billion)

### 3. Google 推出 Gemini 3.8 Flash 与 Gemini 3.8 Flash Cyber，正面对标 Astra 编程与安全
- **要点**：Google DeepMind 9 月 2 日发布 Gemini 3.8 Flash（内部代号 Skimaki），定位"最智能的主力模型"，同步上线安全变体 Gemini 3.8 Flash Cyber。
- **详情**：官方称 3.8 Flash 在软件工程、Agent 任务及多步骤推理上相比 3.7 Flash 有明显提升，内部测试编码能力优于 Anthropic 的 Opus 系列；9 月 4 日 B.AI 等第三方 API 平台完成接入。安全变体 Gemini 3.8 Flash Cyber 主打漏洞检测与自动修补，与 OpenAI Astra 的网络安全叙事直接对撞。
- **影响**：这是 Google 结束十余年最长股价月度连跌后的关键反击，也意味着"御三家"（OpenAI / Anthropic / Google）中第三名的位置正被 Meta Muse Spark 与阿里 Qwen 逼近；对开发者而言，Flash 系列的低延迟 + Grounding 组合正在挤压中端 Agent 模型的市场。
- 🔗 [新浪财经：谷歌 Gemini 3.8 Flash 上线，编码优于 Opus](https://finance.sina.com.cn/world/2026-09-02/doc-iniqnawq1272050.shtml)
- 🔗 [新浪：谷歌又发新模型，Meta AI 负责人隔空喊话](https://finance.sina.com.cn/tech/roll/2026-09-03/doc-iniqpqxy2176653.shtml)

### 4. 腾讯混元 Hy4 Preview 轻量版开源，1.5TB 压到 214GB
- **要点**：腾讯混元团队推出 Hy4 Preview 轻量版，把 770B 总参数 MoE 模型的权重从 **约 1.5TB 压缩到约 214GB**，异构设备可联合部署。
- **详情**：Hy4 preview 于 8 月 28 日首发并开源，总参数 770B、激活参数 49B、上下文 100 万 token；9 月 1 日发布的轻量版通过量化 + 权重压缩把落地门槛降到消费级/企业级混合部署可承受的范围，官方重点押注 Coding Agent、工具调用和办公生产力。WorkBuddy 已首发接入并限免 2 周，Hy3 免费期延至 9 月 30 日。
- **影响**：国内开源旗舰第一梯队再添一个"能真装进企业内网"的 770B 选项，直接冲击 DeepSeek、Qwen、Kimi K3 的部署经济性；对 Agent 团队而言，1M 上下文 + 49B 激活是长任务执行的关键卖点。
- 🔗 [新浪：腾讯混元 Hy4 preview 轻量版 1.5TB 压到 214GB](https://finance.sina.com.cn/tech/digi/2026-09-01/doc-iniqhwna1597170.shtml)

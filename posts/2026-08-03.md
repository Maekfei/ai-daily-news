## 🎯 Agent 重点

### 1. 国产大模型包揽 OpenRouter 全球调用量前五，小米 MiMo-V2.5 登顶
- **要点**：全球多模型聚合平台 OpenRouter 最新一周调用量榜单前五全部由中国团队研发，Xiaomi MiMo-V2.5 单周 10.5 万亿 Tokens 位列第一。
- **详情**：央视新闻 8 月 2 日援引 OpenRouter 数据，小米 MiMo-V2.5 单周调用量从数月前的 1.5T 一路涨至 **10.5T tokens**，环比 +12%；紧随其后为月之暗面 Kimi K3、腾讯**混元 3（Hunyuan 3）**（#3、周增速最快）、深度求索 DeepSeek 与阿里通义 Qwen。榜单表明"开放权重 + 低推理成本 + 快速迭代"三重叠加，正把 Agent 与开发者流量从美系闭源模型拉向国产开源阵营。OpenRouter 本身也是收购热点——TechWeb 7 月透露 Stripe 已就近百亿美元估值收购谈判进入深入阶段。
- **影响**：这是国产大模型首次在**全球开发者调用量**维度形成整体压制，直接改变 Coding Agent、Chatbot 应用层的默认模型选型；同时把"OpenRouter 生态"抬升为可与 OpenAI/Anthropic API 抗衡的第三极分发平台。

### 2. Google Earth 上线 Nano Banana 2 图像生成 24 小时被撤回
- **要点**：谷歌 7 月 31 日在 Google Earth 上线基于 Nano Banana 2 的图像生成功能，允许在真实卫星底图上叠加 AI 生成内容；8 月 1 日即因"用户违反政策生成误导内容"下线。
- **详情**：新功能允许全球网页端用户以文本 Prompt 在卫星/航空底图上重绘现实地点，谷歌原定位为"历史场景可视化"；数字伦理研究员 Henk van Ess 等在上线数小时内就展示了**生成虚假事故、军事部署、地标篡改**的案例，PCMag、Cryptonomist 同步跟进。谷歌 8 月 1 日下架该功能并声明"人们迅速利用它违反我们的政策"。这是 Nano Banana 2 集成到消费级地理服务后的**第一次公开回撤**。
- **影响**：把"高精度底图 + 生成式 AI"直接放开给普通用户被证实**门槛太低**，会加速各国监管对地理信息类生成式 AI 的准入审查；Gemini 2.5 Flash Image / Nano Banana Pro 系列后续与地理产品的耦合都需重新评估。

### 3. Anthropic 隐含估值飙至 1.2 万亿美元，首次反超 OpenAI
- **要点**：链上 Pre-IPO 市场对 Anthropic 的隐含估值瞬间冲到 **1.2 万亿美元**，首次超过 OpenAI，被视作模型/Agent 商业化格局变化的市场信号。
- **详情**：36 氪 8 月初报道，二级市场私募平台上的 Anthropic 份额买价推高其**隐含估值至 $1.2T**，与去年 9 月 130 亿美元 F 轮时 1830 亿美元估值相比 6 倍跃升；驱动因素包括企业级 Claude Code / Managed Agents 收入超预期、Fable 5 模型（内部代号 Capybara / Mythos）在企业 Coding 场景对 GPT-5 的压制、以及 Amazon-Anthropic 长期算力协议深化。同期 OpenAI Pre-IPO 隐含估值已回落至 1 万亿美元区间。**注意**：链上 Pre-IPO 隐含价格波动大、非官方定价，仍需以正式融资轮作为最终锚点。
- **影响**：如果这一定价传导到 Anthropic 下一轮官方融资，将确立 Claude 家族作为"企业级 Agent 首选模型"的定价权，加剧 OpenAI 在**API 价格 + Agent 协作层**双线降本压力（近期 GPT-5.6 Luna 已下调 80%）。

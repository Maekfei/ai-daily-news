## 🎯 Agent 重点

### 1. Anthropic 发布 Claude Fable 5.1 / Mythos 5.1，主打长时智能体编码
- **要点**：Fable 5.1 在 Terminal-Bench-Science 0.1 得分 52.6%（前代翻倍）、编码测试 +13%，缓存读取价格直降 75%。
- **详情**：北京时间 9 月 2 日（当地 9 月 1 日），Anthropic 正式推出 **Claude Fable 5.1** 与 **Claude Mythos 5.1**，两者共享同一基础模型，Mythos 通过"可信访问计划（Project Glasswing）"提供更严格安全防护，Fable 面向所有用户。官方定位为"面向长时间运行的智能体编码、知识工作与研究"的模型。除性能提升外，本次更新罕见地"卷价格"——**缓存读取（cache read）费用相比 Fable 5 降低约 75%**，长上下文场景整体使用成本最多下降 45%，被视为回应客户对高价与过严安全防护的直接调整。发布同期还展示了 Fable 5.1 设计蛋白质结合剂成功率接近 50%、把七款开源模型 GPU 推理速度最多提升 2.5 倍、复原 NASA 30 年前雷达数据生成高精度金星地图等 Agentic-for-Science 用例。
- **影响**：这是继 8 月 GPT-5.6 Sol 之后，前沿模型再一次在"能力↑成本↓"两轴同时突破——将 Agentic 编码与科研 Agent 的边际使用成本压向新的低点，直接抬高 Cursor / Claude Code / Codex 等下游 Agent 产品的性价比预期，也让"缓存价格战"成为 2026 下半年模型竞争新战线。

### 2. 工信部启动"人工智能应用服务商培育专项行动"，Agent 落地进入国家名录
- **要点**：官方文件 9 月 1 日印发，将靶向建立"AI 应用服务商资源池"，年底目标突破 2000 家入池。
- **详情**：工业和信息化部办公厅《关于开展人工智能应用服务商培育专项行动的通知》（工信厅科函〔2026〕414 号）9 月 1 日通过官网公开，要求各省市工信主管部门筛选、上报"懂行业痛点、通技术方案、擅集成交付"的**AI 应用服务商**，进入部级线上资源池。文件同步给出**服务商资源池模板、信息报送要求、服务团信息表**等 5 个附件，要求聚焦"制造、金融、医疗、政务、教育、能源"6 大行业，重点考察企业在多模态大模型、智能体（Agent）、RAG/知识库集成、安全合规四个方向的能力。这是国家部委首次以行政名录形式定义并牵引 AI Agent / 应用侧供给。
- **影响**：Agent 赛道从"技术叙事"迈入"招投标可采名录"，头部及中腰部 Agent 服务公司将围绕入池展开新一轮竞速，同时也意味着国产大模型下游的 SI（系统集成商）体系将被整体重构；预计 Q4 起将出现批量地方政府 + 央国企"入池即中标"式采购案。

### 3. Google 发布 Agentic Video Understanding，Gemini 3.7/3.6 Flash 首入 Agent 视频域
- **要点**：Gemini API 9 月 1 日更新，把"智能体视频理解"作为独立能力开放，允许 Agent 自主检索、剪辑并推理长视频。
- **详情**：根据 Google AI for Developers 官方 changelog，**Gemini API 于 2026-09-01 发布 Agentic Video Understanding**，覆盖 Gemini 3.7 Flash、3.6 Flash 与新版 3.8 Flash 预览。新能力允许调用方以 Agent 循环方式对 30 分钟以上长视频进行**检索式帧采样 + 结构化事件抽取 + 多轮问答**，官方标注在直播回放、监控回溯、教育视频批注等场景收益最大。这是 Gemini 系列首次将"视频"作为一等 Agent 上下文（而非单次多模态输入），也补齐了此前 3.7 Flash 更新中留下的 agent-in-video 空档。
- **影响**：随着 Anthropic 主攻长时编码 Agent、Google 主攻长视频 Agent，前沿模型的"Agentic 分工"正在形成——各家在自己相对领先的模态上先做出"Agent-native"能力，再向外扩展。对下游意味着，视频类 SaaS（教育、监控、内容审核）2026 Q4 或将迎来第一批基于 Gemini 3.7 Agentic Video 的重构。
- 🔗 [Google AI for Developers · Gemini API Release Notes (Sep 1, 2026)](https://ai.google.dev/gemini-api/docs/changelog)

### 4. 科大讯飞开源"星火 X2.5-4B / 1.7B"端侧模型，原生 1M 上下文
- **要点**：讯飞 9 月 1 日开源两款端侧通用模型，主打车载与智能硬件；预告 9 月 7 日发布 293B 参数基座。
- **详情**：**科大讯飞**在 2026-09-01 正式开源 **星火 X2.5-4B** 与 **星火 X2.5-1.7B** 两款端侧通用大模型，原生支持 **1M token** 长上下文，重点面向车载智能座舱、AIoT 边端、机器人本体等"离线可用"场景。讯飞同步预告 **9 月 7 日**将发布 **293B 参数**的下一代基座模型。此次开源使星火成为继 Qwen、GLM、DeepSeek、Kimi 之后**参数梯度最完整的国产开源家族**之一（1.7B / 4B / 293B 端-边-云三档）。
- **影响**：端侧 1M 上下文让"车机跑本地长文档 Agent"从概念落地成商用可交付形态，配合 293B 云端基座，讯飞正在补齐 Agent 生态的算力-模型-场景闭环；对手机、汽车、机器人厂商的模型选型将形成新一轮压力。

# 🤖 今日 AI 要闻 · 2026-07-25

> Anthropic 深夜发布 **Claude Opus 5**，以 Fable 5 一半的价格逼近前沿智能；同日 Stripe 洽购 **OpenRouter** 估值飙至 100 亿美元，Agent 时代的"支付—路由—模型"三层堆栈开始被重定价。

## 🎯 Agent 重点

### 1. Anthropic 发布 Claude Opus 5：价格砍半、Agent 编码接近 Fable 5
- **要点**：Opus 5 在 Frontier-Bench v0.1 上性能约为 Opus 4.8 的 2 倍以上，ARC-AGI 3 得分是次优模型的 3 倍，而 API 价格维持 **每百万 token 输入 $5 / 输出 $25**——只有旗舰 Claude Fable 5 的一半。
- **详情**：北京时间 7 月 25 日凌晨，Anthropic 官网上线 **Claude Opus 5**，官方定位为「thoughtful and proactive」的 Agent 主力模型。核心亮点：**智能体编码 SWE-bench Verified 通过率追平 Fable 5 前 5%**、金融任务 Vals Finance-Agent 得分创新高、可持续自主运行时间由 Opus 4.8 的约 7 小时提升至 **接近 24 小时**。发布同时进入 Claude API、Amazon Bedrock、Google Vertex AI；此前引入的 Claude Code、Computer Use 与新版 Skills 全线默认切换为 Opus 5。官方明确表示："Opus 5 没有推进高风险两用能力的前沿"——生物研究和攻击性网络任务由更受管控的 Mythos 5 承担，Anthropic 延续了刻意不在网络攻击类任务上训练主力商用模型的一贯策略。
- **影响**：这是继 GPT-5.6 Sol、Gemini 3.6 Flash 之后，2026 下半年"前沿智能价格战"的关键一枪：**同等智能水平的 token 成本又被压掉一半**。对 Cursor、Devin、Windsurf、Claude Code 等编码 Agent 而言，默认模型升级为 Opus 5 之后，长任务成功率和上下文预算都是显著跃迁；对国产阵营（Kimi K3、Qwen3.8、DeepSeek V4 Pro）则形成明显的"性价比锚点"压力。

### 2. Stripe 洽购 OpenRouter，估值飙至 100 亿美元——支付巨头切入 Agent 路由层
- **要点**：支付巨头 Stripe 就 100 亿美元收购全球最大 AI 模型聚合平台 OpenRouter 进入深度谈判，较其 5 月份融资时的 **13 亿美元** 估值暴涨约 **7.7 倍**。
- **详情**：据《华尔街日报》及多家外媒于 7 月 24 日报道，Stripe 与 **OpenRouter** 的收购谈判正快速推进，交易估值约 **100 亿美元**，目前尚未签署最终协议。OpenRouter 是一个统一 API 接入 GPT-5.6、Claude Opus 5、Gemini 3.6、Kimi K3、DeepSeek V4 等**数百款主流模型**的路由层，日调用量已破千亿 token 级别，是开发者和 Agent 应用的"模型 API 总闸"。Stripe 自 2023 年为 ChatGPT Plus 提供订阅支付以来，一直在向 AI 基础设施扩张：Bridge（稳定币）+ Privy（钱包）+ 现在的 OpenRouter，形成"支付—钱包—模型路由"的 Agent 经济全栈。
- **影响**：这是**首个百亿美元级别的 Agent 中间件收购**。若成交，Stripe 将同时成为 Agent 经济的**结算通道 + 模型入口**，控制"每一次 token 消费" 的记账权；对 OpenAI、Anthropic、Google 而言，他们的模型开始通过一个新的"消费税节点"到达开发者；对国内的火山方舟、百炼、腾讯知识引擎等聚合平台，这个交易直接给出了估值锚——用户日调用规模 × Agent 时代的支付溢价。

### 3. 北京发布全国首个省级智能体专项政策：一人公司、Token 计费、最高 1 亿元资金支持
- **要点**：《北京市关于加快智能体引领发展的若干措施》正式印发，是全国**第一部**在省级层面系统支持 AI Agent 的政策文件，单项目资金支持最高 **1 亿元**。
- **详情**：7 月 23 日下午，北京市发改委、市科委、经信局等四部门联合召开专场新闻发布会，发布《若干措施》共 **10 条**，围绕"技术—应用—产业—生态"四条主线布局。政策首次在地方层面明确认可**一人公司（OPC，One-Person Company）**和"超级个体"创业形态，同时鼓励前沿岗位**前沿部署工程师（FDE）**、按 **Token 词元价值计费**的新型商业模式，以及**驾驭层工程**（Governance & Orchestration Layer）作为底层基础模型之上的关键工程能力。资金端设立最高 **1 亿元**单项目支持，用于基础模型迭代、行业智能体规模化和安全治理平台建设。
- **影响**：北京把"从大模型到智能体交付"上升为省级顶层设计，意味着 Agent 不再只是产品概念，而是被纳入**产业政策 + 财政工具 + 商业模式**三重激励。上海（WAIC 主场）、深圳（芯片）、杭州（DeepSeek/宇树）之外，北京正式在**智能体交付**这一战略高地上确立自己的位置。国内 Agent 创业公司在 2026 下半年将可以在北京拿到明确的"政策 + 客户 + 资金"三合一支持。

### 4. 腾讯 TEG 撤销大语言模型部/多模态模型部，合并成立"基础模型部"，姚顺雨执掌
- **要点**：腾讯技术工程事业群（TEG）7 月 24 日官宣组织调整，撤销原**大语言模型部**与**多模态模型部**，合并成立**基础模型部**，由首席 AI 科学家**姚顺雨**统一负责，直接向 TEG 总裁卢山汇报。
- **详情**：本次调整是自 2025 年 12 月姚顺雨（前 OpenAI 研究员、CoT/ReAct 论文核心作者）空降腾讯以来最深层次的一次整合。基础模型部将负责混元大模型的**前沿技术探索**与**基础模型研发**，同时接管原两个部门的团队与业务，混元 4.0 及后续代际将由该部统一牵头。腾讯官方口径明确：合并是为「进一步提升模型研发和协同效率，探索全模态模型的智能上限」。此前混元 3.0 在多项中文榜单落后于 Kimi K3、DeepSeek V4 Pro、Qwen3.7-Max，双线分兵被外界批评是掣肘之一。
- **影响**：腾讯此次调整对标 OpenAI 的"single research org"、Anthropic 的 Frontier Research 建制，把大模型研发从"业务导向的双线并行"改为**统一底座、集中攻坚 AGI**。对国内基础模型格局而言，六大厂（阿里/字节/腾讯/百度/华为/DeepSeek + 智谱/月之暗面）里，腾讯完成了最后一次核心组织级简化——2026 下半年混元的追赶速度值得重点关注。

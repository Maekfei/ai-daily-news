## 🎯 Agent 重点

### 1. OpenAI 正式断供 Cursor：11 月 12 日起停止模型 API
- **要点**：SpaceX 以 600 亿美元收购 Cursor 母公司 Anysphere 两周后，OpenAI 宣布终止合作。
- **详情**：OpenAI 于当地时间 8 月 28 日发布官方声明，已通知 SpaceX 计划终止向旗下 AI 编程平台 Cursor 提供模型服务，拟定停止日期为 2026 年 11 月 12 日，按合同规定的最长期限提前通知。OpenAI 引用 Elon Musk 旗下多家公司过往多次违反服务合同作为决策依据，声明由 Sam Altman 团队公开发布。Cursor 此前是 OpenAI 模型最大的 Coding Agent 消费端渠道之一，年 ARR 估算 3–5 亿美元；到 8 月 30–31 日，Cursor 已启动向 Anthropic Claude Opus 4.7 和 Google Gemini 3.7 的默认模型迁移。
- **影响**：这是 AI Coding Agent 赛道首次出现"平台级模型断供"，暴露了 Agent 产品对基础模型供应商的深度依赖；行业普遍预期 Cursor 将全面倒向 Claude Code / Gemini，Anthropic 与 Google 有望瓜分 OpenAI 让出的 Coding Agent 份额。
- 🔗 [OpenAI 官方声明 · Our decision on Cursor following its acquisition by SpaceX](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/)
- 🔗 [腾讯新闻 · 刚花 600 亿美元收购 Cursor 两周，OpenAI 就断供模型](https://news.qq.com/rain/a/20260830A04UZ500)

### 2. 腾讯混元 Hy4 preview 开源第 3 天登顶 Hacker News，Token 定价公开
- **要点**：770B 总参数、49B 激活、1M 上下文的 MoE 模型延续开源热度，商业化路径明朗。
- **详情**：8 月 30 日至 31 日，腾讯混元 Hy4 preview 在 Hacker News 保持热榜第一，同时腾讯云 TokenHub 正式挂牌其 API 定价：输入 4 元 / 百万 Token、输出 16 元 / 百万 Token（0–128K 上下文档位）；WorkBuddy、CodeBuddy 国内版及国际版继续提供 2 周限时免费。据模型卡数据，Hy4 preview 在 163 名内部专家的盲测中综合排名进入开源模型第一梯队，代码任务上超越 DeepSeek V4 与 Qwen3.8-Max，成为国产开源阵营 Agent 场景的新旗舰之一。
- **影响**：Hy4 preview 将首次让企业能以国产开源方案覆盖百万上下文级别的 Agent 工作流，同时 WorkBuddy 借势打造"腾讯 AI Native Work OS"入口——这直接与字节"豆包工作"、阿里通义 Agent Studio 形成正面竞争。

### 3. 字节跳动"豆包工作"正式上线：TRAE + 扣子并入，Agent 打通飞书
- **要点**：字节把 AI 编程（TRAE）与 Agent 开发平台（扣子）统一并入豆包，推出面向生产力场景的 Agent 品牌。
- **详情**：豆包工作 8 月 25 日发布，8 月 30 日新增独立电脑版应用与飞书深度集成；用户登录或更新即赠送 30 天免费订阅权益。产品能围绕用户目标自主拆解任务、调用工具、持续推进复杂工作流程，覆盖文档处理、会议纪要、表格分析、跨系统操作。此次组织调整前，TRAE 与扣子分属产品研发和工程架构部，此番整体并入豆包体系，字节 AI 办公主线正式收敛。
- **影响**：这是 Agent 从"聊天入口"到"办公主入口"的关键一跃；字节以豆包用户规模 + 飞书企业场景 + TRAE/扣子技术积累构成三合一，与腾讯 WorkBuddy、阿里通义灵码、微软 Copilot Studio 直接对撞企业 Agent 平台的入口之争。

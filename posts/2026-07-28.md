## 🎯 Agent 重点

### 1. MCP（Model Context Protocol）年度大版本今日发布，Agent 生态全面无状态化
- **要点**：由 Anthropic 主导、OpenAI 与 Google 共同参与治理的 MCP 于**今日（2026-07-28）**正式发布 `2026-07-28` 版本，是协议诞生以来最大规模的一次重构。
- **详情**：新版核心变更是**完全去除 Session ID**，会话状态由请求头 + 幂等 token 承载，从而适配 Serverless / 边缘部署；同步上线**官方 MCP Registry** 目录服务，将现有零散的 10 万+ Server 集中登记与签名分发。据其官方生态数据，MCP SDK **月下载量已突破 9700 万次**，Gemini 3.6 Flash、Claude Opus 5、GPT-5.6 Sol 均已宣布原生兼容。OpenAI 也在同期推出 **Secure MCP Tunnel**，把 Tool 调用统一走加密审计通道。
- **影响**：无状态化 + 官方注册表，标志 MCP 从"实验性 RFC"进入类似 HTTP/1.1 的成熟阶段；但存量 Server / SDK 需在 8 月完成迁移，短期出现兼容性阵痛，会促使企业重新盘点自研工具接入策略。

- 🔗 [MCP 官方规范仓库 modelcontextprotocol/specification](https://github.com/modelcontextprotocol/specification/releases)

### 2. Sam Altman 携 ChatGPT Work "多小时自主研究"演示访华盛顿，推动 AI 政策
- **要点**：OpenAI CEO Sam Altman 于 **7 月 27 日**赴华盛顿，向立法者展示 ChatGPT Work 的 Agentic 能力，同期美国《AI 行动计划》一周年立法窗口临近。
- **详情**：据 Politico 独家报道，Altman 此行随身演示了 ChatGPT Work 的一段**多小时自主深度研究流程**——从公开数据源采集、跨表格分析到自动生成简报，全程无人类干预。他将在联邦贸易委员会（FTC）AI 峰会发言，并与国会两党领袖闭门会晤，重点游说的方向包括：允许出口部分算力等级至盟友国家、明确 AI 责任分配规则，以及推进联邦级 AI 采购通道。ChatGPT Work 自 7 月 9 日全球上线后，被 OpenAI 官方定位为"能连续工作数小时的通用工作智能体"，与 GPT-5.6 Sol/Terra/Luna 深度绑定。
- **影响**：这是 Altman 首次以 Agent 而非聊天机器人为筹码进行政策沟通，暗示美方监管重心正从"模型训练算力"下移到"部署侧自主行为"层面；对企业客户，也是 ChatGPT Work 从 Demo 走向政府/大企业采购目录的关键窗口。

### 3. OpenAI、Anthropic 被曝游说美国限制中国开源模型，Kimi K3 成焦点
- **要点**：凤凰科技援引多位知情人士称，OpenAI 与 Anthropic 已在华盛顿与美国监管机构闭门沟通，试图**推动加强对中国开源模型（含 DeepSeek、Kimi、Qwen）的使用与二次商用限制**。
- **详情**：报道指双方向政策制定者呈交"开源前沿模型对本土商业模式的稀释效应"评估——尤其是 7 月 17 日 Moonshot AI 发布的 **Kimi K3（2.8 万亿参数、原生 1M 上下文）**上线 48 小时即打爆推理集群，其在 Agentic Coding、多智能体协作等基准逼近或超过 Claude Sonnet 5 / GPT-5.6 Terra。OpenAI 战略未来负责人 Dean W. Ball 此前公开发帖批评"开源前沿模型是减速主义、会抑制资本投入"，与此次闭门游说口径一致。
- **影响**：若最终立法或以出口管制方式落地，海外企业接入中国开源模型的门槛将显著抬高，加速开源阵营与美国前沿闭源阵营的技术脱钩；对国内厂商而言，"权重全开 + 前沿性能"策略仍是当下最有效的地缘博弈手段。

### 4. Moonshot AI 发布 PerceptionBench：无一前沿模型视觉感知过 60%
- **要点**：月之暗面（Moonshot AI）今日公开新评测 **PerceptionBench**，测试 GPT-5.6 Sol、Claude Opus 5、Gemini 3.6 Pro、Kimi K3-VL 等 12 款前沿模型的视觉感知能力，**没有一款准确率突破 60%**。
- **详情**：PerceptionBench 聚焦"看没看见"这一低阶感知层（细粒度计数、被遮挡目标、小目标定位、多物体空间关系等 8 类任务），刻意避开需要复杂推理的问题；结果显示前沿多模态模型在纯 low-level 感知上依然离人类差距明显，最强的 Kimi K3-VL 仅 58.7%。这与近期 GUI Agent、机器人 Agent 屡屡"点错按钮 / 抓错物体"的现象直接呼应。
- **影响**：为 VLA、GUI Agent、具身智能等强感知依赖赛道提供了明确的诊断工具，也解释了为何"推理跑分很高、真正部署仍脆弱"——短板并不在 CoT，而在感知底座。

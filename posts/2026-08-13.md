# 🤖 今日 AI 要闻 · 2026-08-13

> Grok 4.6 正式发布对标 GPT-5.6 Sol；腾讯 Q2 财报揭示混元调用量增 68 倍、AI 资本开支飙升 176%，「模型 × 智能体」双螺旋成为国内大厂主线。

## 🎯 Agent 重点

### 1. SpaceXAI 发布 Grok 4.6，主打「长时运行智能体」
- **要点**：马斯克 SpaceXAI（前 xAI）推出 2 万亿参数级新模型 Grok 4.6，性能对标 GPT-5.6 Sol / Claude Opus 5，价格约为对手三分之一。
- **详情**：Grok 4.6 于 8 月 12 日上线 API 与 Grok App，重点面向**长时间运行的智能体**（long-running agents）场景，改进了工具调用稳定性、超长上下文记忆与多轮 planning。SpaceXAI 声称在 Artificial Analysis 综合榜上并列全球第三，与 Kimi K3 接近；API 输入价 $1.5 / 输出 $6 每百万 tokens，较 GPT-5.6 Sol 便宜约 66%。
- **影响**：Grok 首次以「智能体原生」定位切入前沿模型价格战，进一步压低企业跑 Agent 的单位成本，同时给 Anthropic / OpenAI 的高端定价施加压力。
- 🔗 [Unite.AI：SpaceXAI Launches Grok 4.6 for Long-Running Agents](https://www.unite.ai/spacexai-launches-grok-4-6-for-long-running-agents/)
- 🔗 [9to5Mac：SpaceXAI releases Grok 4.6, claims parity with GPT-5.6 Sol and Claude](https://9to5mac.com/2026/08/12/spacexai-releases-grok-4-6/)

### 2. 腾讯发布 Q2 财报：混元调用量增 68 倍，AI 资本开支飙至 527.8 亿
- **要点**：腾讯 2026Q2 营收 2047.9 亿元同比 +11%，混元大模型 API 调用量同比暴涨 **68 倍**，AI 资本开支同比 **+176%** 至 527.8 亿。
- **详情**：财报显示新 AI 产品（混元、元宝、WorkBuddy、CodeBuddy、小微）对 Non-GAAP 经营利润的影响达 **105 亿元**，较一季度显著扩大；WorkBuddy PC 端 6 月访问量 2097 万次，居国内办公智能体第一，且超过第 2、3 名之和；混元 Hy4 将于近期发布。总裁刘炽平表态：「看到真正爆发机会前投资谨慎，一旦看到就加大投入」。
- **影响**：腾讯从此前的「慢半拍」转为在 Agent 层强攻应用侧，标志着国内互联网大厂 AI 竞争正式进入「模型 + 智能体」双螺旋阶段。

### 3. Anthropic 首季度盈利：Q2 营收 109 亿美元，运营利润 5.59 亿
- **要点**：Anthropic 向投资者披露 2026Q2 营收 **109 亿美元**，季环比 +130%，实现首个季度**运营盈利 5.59 亿美元**，比原计划提前约两年。
- **详情**：驱动力来自 Claude Code、Claude Sonnet 5 / Opus 5 的企业 API 大规模落地——OpenAI 前 CFO 曾透露 Anthropic API 收入已超 OpenAI API 收入。今日多家外媒（AI Tools Recap 等）在 Q2 财季文件公开后交叉验证了这一数字，Anthropic 上半年累计营收约 155 亿美元。
- **影响**：Anthropic 成为**首个季度层面正式盈利的前沿大模型公司**，AI 领域「烧钱换用户」的叙事正被打破；同时也让 Anthropic 在下一轮估值谈判（据传目标 3000 亿+）中获得强硬底气。

### 4. Meta 重返开源：MSL 发布 30B 本地 Agent 模型 Muse Glimmer
- **要点**：Meta Superintelligence Lab（MSL）于 8 月 10 日以 **Apache 2.0** 协议开源 **Muse Glimmer（30B）**，专为常驻本地的 Agent 工作流深度优化。
- **详情**：模型配套官方 4bit 量化版本，可在 24GB / 32GB 显存的消费级 GPU（RTX 4090、M-series Mac 等）本地跑通，量化对 Agent 任务几乎无衰减。扎克伯格同步发表 6500 词长文《分布式超级智能》，将 Meta AI 路线正式转向"人人可本地拥有的智能体"，LeCun 亦公开力挺。这是 Meta 自 Llama 3.3 之后一年多来首次开放前沿权重。
- **影响**：本地端 Agent 生态迎来第一款「消费级显卡可跑 + 商业友好协议」的强模型，与 Muse Spark 1.2 云端旗舰形成组合，冲击 OpenAI/Anthropic 的封闭商业 API 主导地位。
- 🔗 [IT之家：Meta 开源 30B AI 模型 Muse Glimmer](https://www.ithome.com/0/988/007.htm)
- 🔗 [51CTO：Meta 重回开源——Muse Spark 1.2 + 30B 端侧 Agent](https://www.51cto.com/article/852576.html)

### 5. OpenAI Codex & ChatGPT 正式登陆 Linux
- **要点**：OpenAI Codex 团队负责人 Thibault Sottiaux 官宣，Codex CLI 与 ChatGPT 桌面客户端在 Linux 平台正式 GA，覆盖 Ubuntu / Debian / Fedora / Arch。
- **详情**：过去 Linux 用户长期只能通过网页版或第三方 wrapper 使用 Codex Agent；今日发布的官方版本支持系统级快捷键、原生文件系统访问、后台常驻子 Agent，以及与 tmux / VS Code Remote 的深度集成。这一里程碑意味着 OpenAI 在开发者主战场终于补齐了操作系统覆盖。
- **影响**：Linux 是 90% 生产服务器与大部分 AI 工程师主力开发环境，Codex 官方入驻将进一步挤压 Cursor Agent / Claude Code 在开发者市场的份额。

## 🎯 Agent 重点

### 1. DeepSeek 开源 Agent 运行时框架 Harness v0.1
- **要点**：DeepSeek 从"做模型"进入"做 Agent 执行层"，以 MIT 协议开放 Harness 框架，主打"一切皆插件"。
- **详情**：8 月 13 日深夜，DeepSeek 在官宣 V4-Pro 转正 2 小时后甩出第三张牌，发布开发者预览版 DeepSeek Harness（dsh）v0.1，底层由 Cordis 驱动，把模型、工具、会话、沙箱、Agent 编排全部拆成可插拔组件，仓库地址 `deepseek-ai/deepseek-harness`。该项目一经开源即被媒体称为 GitHub 上涨速度最快的 Agent 框架之一，社区已同步孵化 `awesome-dsh-plugin` 插件仓库。
- **影响**：这意味着模型厂商正把竞争从 "谁的模型更聪明" 推进到 "谁的运行时更好用"，与 Anthropic Claude Code、字节 DeerFlow、港大 nanobot 形成正面对抗，Agent 基础设施进入 Harness 军备竞赛阶段。
- 🔗 [DeepSeek Harness GitHub 官方仓库](https://github.com/deepseek-ai/deepseek-harness)
- 🔗 [AIHub：DeepSeek Harness 开发者预览版发布 MIT 开源](https://www.aihub.cn/news/deepseek-harness-release/)

### 2. Zed 发布 Delta：面向 AI Agent 的多人协作编程环境
- **要点**：Zed 团队推出独立新应用 Delta，把"Agent 写代码"从单机行为升级为多人实时协作。
- **详情**：8 月 12–13 日，高性能编辑器 Zed 团队正式公开 Delta 私测。Delta 是 Zed 之外的独立应用，围绕 ACP（Agent Client Protocol）构建，允许多个开发者与多个 AI Agent 在同一代码库上同屏协作：任意代码行可添加对话式评论，评论随代码演进，Agent 会话与 review 讨论同屏可见，主打把 "写代码 / 评审 / 与 Agent 对话" 三条流打通。这是继 Zed 主推 ACP 协议后的又一步——把编辑器变成 Agent 协作平台。
- **影响**：coding agent 的下一站不再是"更强的单体 agent"，而是多 agent + 多人协作。Cursor、Copilot、Claude Code 等编程 Agent 都可通过 ACP 接入 Delta，编程工具的竞争从 IDE 变成 orchestration layer。
- 🔗 [OSCHINA：Zed 推出多人协作 AI 编程环境 Delta](https://www.oschina.net/news/501922)
- 🔗 [AItoolly：Zed Delta 多人 AI Agent 协作环境详细报道](https://aitoolly.com/ai-news/article/2026-08-13-zed-introduces-delta-a-new-multiplayer-environment-for-collaborative-coding-with-ai-agents-and-real)

### 3. Google 推出 Gemini 3.7 Flash：三周迭代，专攻 Agent 与编程
- **要点**：3.7 Flash 首发定价为 3.6 Flash 的一半，官方宣称是"迄今最智能的 Flash 级 coding/agent 主力模型"。
- **详情**：美国当地时间 8 月 13 日，Google 发布 Gemini 3.7 Flash，距 3.6 Flash 仅约三周。本次升级聚焦软件工程、Agent 工具调用、Web 开发和复杂知识工作，官方在 changelog 中列为 "August 13, 2026" 条目。首发优惠价为原 Flash 价的 50%，Flash 系列已进入近乎月度迭代节奏，直接把价格战推进到 Agent 场景腹地。
- **影响**：Google 用低价 + 高频迭代死磕 Anthropic/OpenAI 的 Agent 编码份额，coding agent 成本进一步下探；开发者选型将更看重"每美元推理智能密度"。

### 4. xAI 发布 Grok 4.6：智能指数追平 GPT-5.6 Sol，主攻长任务 Agent
- **要点**：SpaceXAI（xAI 更名后）在 Artificial Analysis 智能指数上拿到 61 分，正式追平 GPT-5.6 Sol。
- **详情**：8 月 12–13 日，xAI 发布 Grok 4.6。模型沿用 4.5 的 1.5T 参数基座，靠后训练把 Artificial Analysis Intelligence Index 从 56 拉到 61，追平 OpenAI 的 GPT-5.6 Sol。升级重点转向 Long-horizon Agent（长任务智能体）与 AI 编程，上下文扩展至 50 万 token 级别，标准 API 定价每百万输入 2 美元 / 输出 6 美元，Fast 变体为 2 倍。
- **影响**：前沿模型的差距被压缩到几分之内，"智能指数"作为区分维度价值下降；下一轮竞争将围绕"能否稳定跑完 8+ 小时的多步 Agent 任务"展开。

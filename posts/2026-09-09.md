## 🎯 Agent 重点

### 1. Cognition（Devin 母公司）20 亿美元 E 轮融资，估值 480 亿美元
- **要点**：Devin ARR 逼近 9 亿美元，编码 Agent 赛道估值 4 个月翻近一倍。
- **详情**：北京时间 9 月 9 日凌晨，AI Coding Agent 公司 **Cognition** 正式官宣完成 **20 亿美元 E 轮融资**，由 **Andreessen Horowitz** 与 **Founders Fund** 领投，投后估值 **480 亿美元**——相比 5 月上一轮的 260 亿美元几乎翻倍。Cognition 同时披露旗舰产品 **Devin**（AI 软件工程师 Agent）当前 ARR 已从 5 月的 **4.92 亿美元** 增长至接近 **9 亿美元**（公司口径），付费企业客户覆盖 Meta、Ramp、MongoDB 等；本轮新增 Nvidia、Lightspeed、Neo 等参投。
- **影响**：这是 SpaceX 6 月 600 亿美元收购 Cursor 之后编码 Agent 赛道最大单笔融资，也把"自主软件工程师"从技术故事推向了主流企业采购标品；资本市场已开始按"Devin ARR × 55 倍 P/S"给编码 Agent 定价，短期内 Windsurf、Cline、Zed 等竞品的估值锚也会随之上移。

### 2. Mistral 拿下三星领投 30 亿欧元 D 轮，欧洲 AI 融资纪录再刷新
- **要点**：估值 210 亿欧元一年翻倍，三星将 Mistral 深度嵌入半导体制造与终端设备。
- **详情**：9 月 8 日，法国大模型公司 **Mistral AI** 宣布完成 **30 亿欧元（约 234 亿元人民币）D 轮融资**，投后估值约 **210 亿欧元（约 1640 亿元人民币）**，由 **三星电子** 领投，NVIDIA、a16z、Bpifrance 等跟投。作为战略合作，三星将把 Mistral 旗舰大模型和 **Mistral Compute** 智能体平台部署进自身半导体制造流程，用于晶圆厂缺陷检测、良率优化以及 Galaxy 系列终端的设备端 AI。这也是欧洲科技行业史上最大单轮股权融资。
- **影响**：三星以战略投资+客户的双重身份押注 Mistral，标志着"主权 AI"从政策口号进入生产链条——欧洲玩家用真金白银证明开源阵营仍可与 OpenAI、Anthropic 掰腕子；对 NVIDIA 而言，则是继 OpenAI、xAI 之后又一枚"算力+资本"双绑定的战略资产。

### 3. OpenAI"万 Agent 集群"攻克百年数学难题，Astra 首次驱动机器人绘画
- **要点**：10,000 个 GPT-6 Astra 实例并行推理 6 周，产出可发表论文。
- **详情**：9 月 8 日凌晨，OpenAI 通过 AlphaSignal 披露一项 Agent 集群实验：以 **GPT-6 Astra** 为核心的 **10,000 个智能体并行运行 6 周**，围绕一道 **1926 年提出的组合几何猜想**（Kakeya 型问题变体）展开分工——分为提假设、验证子引理、搜索文献、写证明四种角色——最终产出一份 **83 页手稿**，由 3 位数学家匿名评审后确认结论正确、可投稿到年度 top 期刊。同日 OpenAI 官方 X 放出 Demo：**Astra** 通过 ChatGPT MCP 工具接口远程控制一台六轴机器人手臂，把生成的图像逐笔"画"到真实画布上，端到端从 prompt 到笔触延迟约 2 秒。
- **影响**：这是继"自动研究实习生"里程碑之后 OpenAI 给出的"Agent 群体智能"实证——将模型能力放大器从"上下文长度"转向"并行智能体数量"；机器人臂 Demo 则进一步展示 Astra 从数字域走向物理域的可编程接口，为具身智能公司提供了新的模型底座选项。

### 4. 蚂蚁集团联合清华发布 AReaL v1.0，主打 Agent 一键接入强化学习
- **要点**：全异步 RL 框架，把 Agent RL 训练成本从"月级"压到"日级"。
- **详情**：9 月 8 日，蚂蚁集团联合清华大学正式发布并开源大规模异步强化学习训练框架 **AReaL v1.0**（Ant Reinforcement Learning）。核心改动是把 rollout（推理采样）与 training（参数更新）完全解耦，允许同一个 GPU 集群 24 小时并行采样与训练，官方数据显示：在同规模 8×H800 硬件上，训练一次 **7B 参数的可用型代码 Agent** 从主流方案的 **约 30 天**压到 **约 6 天**；同时提供 `Agent-in-the-loop` API，业务方无需改代码即可把现有 LangGraph / AutoGen 智能体接入 RL 训练管线。
- **影响**：这是国内首个瞄准"Agent RL 工业化"的开源基建——过去半年 Agent 训练受限于 RL 成本，只能在少量头部实验室内部跑通；AReaL 让中型创业公司也能拥有自己的 RL 训练闭环，对 Manus、扣子这类 Agent 平台的自训练能力是直接补强。

- 🔗 [CSDN — AReaL v1.0 全异步强化学习训练系统](https://devpress.csdn.net/v1/article/detail/158925352)

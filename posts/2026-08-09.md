## 🎯 Agent 重点

### 1. OpenAI 因 Astra 达"关键"网络安全阈值，暂缓部分研发并启动强化管控
- **要点**：OpenAI 8 月 8 日承认下一代模型 **Astra** 已被列为其《Preparedness Framework》下**首个达到 Critical 级网络安全风险**的模型，公司暂停部分内部工作。
- **详情**：OpenAI 表示无法排除 Astra 具备在**无人类干预下自主发现并利用零日漏洞**的能力，触发框架中的"Critical Cyber"红线，是 AI 公司**首次公开因安全风险自我叫停**旗舰模型研发。接下来 Astra 将被转入更严格的隔离环境：**网络与工具访问受限、加强权重保护、沙箱执行、异常检测**，训练与评测流水线纳入统一监控；美国政府机构及部分 AI 安全组织将参与测试。此前 OpenAI 内部评估还发现 Astra 在 Agent 编程能力上出现"重大突破"，与其网络攻击能力评估直接相关。
- **影响**：这是 Preparedness Framework 落地以来最强力的一次触发，可能重塑前沿模型的**发布准入范式**——从"能力驱动"转向"能力 × 风险双闸门"，并直接影响 GPT-5.6 之后的产品节奏；对 Anthropic Mythos 5 / xAI Grok 4.7 / Google Gemini 顶层型号构成压力，也为 8 月 2 日全面执法的欧盟 AI Act 提供了首例"厂商自评触发"的教科书案例。

### 2. Pokee AI 发布 Pokee-Isaac 28B：10M Token 上下文的企业级 Agent 底座模型
- **要点**：Pokee AI 8 月 8 日发布 **Pokee-Isaac 28B**，一款专为长期运行 Agent 设计、**上下文窗口达 1000 万 Token** 的非纯 decoder-only 基础模型，可在企业 VPC / 本地 / 边缘部署。
- **详情**：Pokee-Isaac 28B 为 **28B 纯文本参数**，通过混合架构解决 Agent 长期运行中的**上下文爆炸**问题——单次会话可容纳数百步 tool call 观察结果、日志与中间推理，避免主流 Agent"每轮压缩摘要 → 丢关键信息"的老毛病。Pokee AI 定位为**企业 Agent 平台**：不开源权重，而通过 **OpenAI 兼容 API + 商业授权**方式在客户边界内部署（On-Prem / VPC / Edge），主打金融、法律、医疗等**数据出不了域**的长任务场景；同步发布技术报告与 Pokee Console 商业化控制台。
- **影响**：与阿里 Qwen3.8-Max 的 1M 上下文、Anthropic Claude 长上下文形成对比，Pokee-Isaac 把"**上下文长度**"作为独立赛道推向 10M 级别；对于 Deep Agents / Devin / Claude Code 类**多小时至多日运行**的编程/研究 Agent，这一档位的上下文可能成为下一阶段基础设施标配。

### 3. DeepSeek 重启第二轮融资，估值约 5000 亿元人民币（~740 亿美元）
- **要点**：DeepSeek 于 8 月 7 日前后**重启此前搁置的第二轮融资**，本轮拟募资近 **80 亿美元**，投前估值约 **5000 亿元人民币（~740 亿美元）**。
- **详情**：这是 DeepSeek 继年初 V4 系列发布之后首次公开的大额融资动作。此前有市场传闻称其原本考虑 A 股 IPO 路径（估值约 4800 亿），此次重开一级市场融资意味着**IPO 时间表可能推迟**、公司选择在算力成本仍高的窗口先补充私募弹药。杭州 DeepSeek 总部主导，梁文锋出面对接，资金将主要用于**下一代模型（V4/V5 系列）训练算力**与国内推理集群扩建，配合此前"V4-Flash 蒸馏版全面压制 V4-Pro"的产品线策略。DeepSeek 已连续四个季度保持开源节奏，是国内估值仅次于字节豆包的第一梯队大模型公司。
- **影响**：5000 亿人民币估值把**中国大模型独角兽的定价锚**推至新高，与月之暗面 Kimi、智谱 GLM、MiniMax 拉开显著差距；国内 VC/PE 对"开源 + 高性价比 API"路线的信心得到强背书；同时也对美方近期讨论中的"限制中国 AI 融资渠道"政策形成短期对冲。
